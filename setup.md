GeoPulse Frontend

This folder contains the React frontend for the GeoPulse: Hyper-Local Retail Mobility Analytics project.

Purpose

The frontend will provide an interactive dashboard for visualizing:

Retail store locations
Customer footfall
Store catchment areas
Customer movement
Cannibalization analysis
